# Чек-листы (PR / релиз)

## PR-чек-лист
- [ ] Цель и влияние на KPI (Sharpe, PF, Max DD) сформулированы
- [ ] Изменения по файлам перечислены; миграции/флаги указаны
- [ ] Юнит-тесты добавлены/обновлены; **coverage ≥ 90%**
- [ ] Смоук-бэктест выполнен; отчёты в `reports/` приложены
- [ ] Конфиги синхронизированы с `unified_config*.json`
- [ ] Нет секретов/персональных данных в коде и логах
- [ ] Документация/roadmap обновлены при изменении логики
- [ ] План отката описан (revert/feature-flag/Safe-Mode)

## DoD для PR
- CI зелёный: `pytest --cov` + смоук-бэктест OK
- Метрики не деградируют вне допусков
- Логи понятны; дубликаты отфильтрованы

## Релиз-чек-лист
- [ ] Все обязательные PR слиты в защищённые ветки
- [ ] Теги/релиз-ноутсы: изменения, риски, откат
- [ ] Конфиги окружений зафиксированы (prod/stage)
- [ ] Мониторинг и алерты проверены (Safe-Mode/CB/Max DD)
- [ ] Отчёты за период собраны (NAV, Sharpe, PF, DD)
- [ ] План пост-релизного аудита (1–3 дня)

## Политика безопасности
- Секреты — только в Secrets CI/репозитория
- Никаких ключей/токенов/ID в коде, патчах и публичных отчётах
