# Binance Futures Portfolio Rebalancer

Асинхронный инструмент на Python для автоматического поддержания рыночно-нейтрального портфеля на фьючерсном аккаунте Binance.

## 📌 Описание системы: Market Neutral 2.0

Система реализует стратегию динамического синтетического хеджирования. Портфель имитирует владение активом без покупки на споте, используя свободную маржу аккаунта как третью активную ногу баланса.

### Целевое распределение:
1. **Long x5 (29%)**: Длинная позиция на фьючерсах.
2. **Short x5 (36%)**: Короткая позиция на фьючерсах.
3. **Margin Simulation (35%)**: Виртуальная позиция актива (x1), работающая на свободной марже.

## 🛡️ Механизмы защиты (Safety Mechanisms)

### 1. Telegram Notifications (VPN Ready)
Интеграция с Telegram через системный VPN (`trust_env=True`):
*   Алерты по **Trailing Stop** (10% от ATH).
*   Предупреждения **Margin Ratio** (Warning ≤5x, Critical ≤2x).
*   Отчеты о фиксации прибыли в сейф.

### 2. Capital Guard & Hysteresis
*   **Isolations:** Параметр `max_capital_usdt` жестко ограничивает объем средств на одного бота.
*   **Soft Hysteresis:** Автоматическое увеличение порога ребаланса в 2 раза при нахождении в локальной просадке (`reference_tpv`).

## 📜 Справочник команд (Cheat Sheet)

### 📊 Сканирование и выбор тикеров
* `python rank_tickers.py` — Быстрый анализ рынка и выбор пар для запуска.

### 🤖 Управление Роем (PM2)
* `pm2 start ecosystem.config.js` — **Запустить всех ботов** по конфигу.
* `pm2 status` — Посмотреть таблицу всех запущенных ботов (статус, память, рестарты).
* `pm2 logs` — Просмотр логов в реальном времени (Heartbeat, ордера, ошибки).
* `pm2 restart all` — Перезапустить всех ботов (применяет изменения в коде или конфигах).
* `pm2 stop all` — Остановить всех ботов.
* `pm2 save` — Сохранить текущий список ботов для автозагрузки после ребута системы.

### 🧪 Одиночный/Тестовый запуск
* `python main.py --config config_zec.json` — Запуск одного бота в текущем окне терминала (для отладки).

### ⚙️ Настройка окружения
* `npm install pm2 -g` — Установить менеджер процессов PM2 (нужен Node.js).
* `pip install -r requirements.txt` — Установить зависимости Python.
