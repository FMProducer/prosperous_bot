# Binance Futures Portfolio Rebalancer: Audit & Precision Edition

Асинхронный инструмент на Python для автоматического поддержания рыночно-нейтрального портфеля. Прошел полный аудит и рефакторинг 20 апреля 2026 года.

## 📌 Описание системы: Market Neutral 2.0 (Z-Logic)

Система реализует стратегию динамического синтетического хеджирования, зарабатывая на **Volatility Harvesting** (сборе волатильности).

### Целевое распределение:
1. **Long x5 (29%)**: Длинная позиция.
2. **Short x5 (36%)**: Короткая позиция (увеличенная доля для компенсации стоимости маржи).
3. **Margin Simulation (35%)**: Виртуальная позиция (x1), работающая на свободной марже.

## 🛡️ Механизмы защиты (Safety Mechanisms)

### 1. Трейлинг-Стоп (Equity Protection)
Бот закрывает все позиции при просадке на 10% от исторического пика (ATH) текущей сессии. 

### 2. Защита Маржи (Margin Ratio)
*   **Warning (5x):** Уведомление в Telegram.
*   **Critical (2x):** Экстренное закрытие всех позиций для предотвращения ликвидации аккаунта.

### 3. Notional Guard & Hysteresis
*   Пропуск ордеров менее 6 USDT.
*   **Soft Hysteresis:** Удвоение порога ребаланса (до 1.0%) при нахождении TPV ниже базовой линии для предотвращения "распиливания" на волатильности.
