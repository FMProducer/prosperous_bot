# Binance Futures Portfolio Rebalancer

Асинхронный инструмент на Python для автоматического поддержания заданных пропорций криптоактивов на фьючерсном аккаунте Binance.

## 📌 Описание системы
Ребалансировщик работает по принципу "Target Allocation":
1. Получает текущие позиции и спот-цены.
2. Рассчитывает общую стоимость портфеля (USDT + стоимость позиций).
3. Сравнивает текущие доли активов с целевыми (из `config.json`).
4. Если отклонение превышает заданный порог (`rebalance_threshold`), бот автоматически выставляет рыночные ордера для восстановления баланса.

## 🏗 Архитектура
- `connector.py`: Низкоуровневая обертка над API Binance (использует `python-binance`). Обрабатывает асинхронность через `asyncio.to_thread`.
- `calculator.py`: Чистая логика расчёта стоимостей, долей и отклонений.
- `executor.py`: Расчёт размеров ордеров с учётом точности (шага лота) и выполнение сделок.
- `main.py`: Основной асинхронный цикл управления, загрузка конфигурации и логирование.

## 🧪 Предложения по развитию

### 1. Бэктестинг (Backtesting)
Для проверки эффективности стратегии на исторических данных предлагается следующая реализация:
- **Data Provider:** Создать модуль для загрузки исторических OHLCV данных (например, из `.npz` файлов проекта или через API).
- **Simulated Connector:** Создать класс `BacktestConnector` (наследник или аналог `BinanceConnector`), который имитирует баланс и позиции в памяти.
- **Engine:** Цикл, который "прокручивает" исторические свечи, вызывает логику ребалансировщика и фиксирует виртуальные сделки с учетом комиссий.
- **Метрики:** Вывод итоговой доходности (Equity Curve), максимальной просадки (Drawdown) и сравнение с доходностью стратегии "Buy & Hold".

### 2. Бумажная торговля (Paper Trading)
Для безопасного тестирования в реальном времени без использования Testnet:
- **Paper Connector:** Реализовать режим, при котором бот получает реальные рыночные цены, но вместо отправки ордеров на биржу (`futures_create_order`) обновляет локальное состояние портфеля в JSON-файле или базе данных.
- **Virtual Balance:** Возможность задать начальный виртуальный баланс (например, 10,000 USDT) и наблюдать за его изменением в реальных рыночных условиях.
- **Индикатор:** Добавить флаг `"paper_mode": true` в `config.json` для мгновенного переключения режима.
