# Binance Futures Portfolio Rebalancer

Асинхронный инструмент на Python для автоматического поддержания рыночно-нейтрального портфеля на фьючерсном аккаунте Binance.

## 📌 Описание системы: Market Neutral 2.0
Система реализует стратегию динамического хеджирования, имитирующую владение базовым активом (BTC) без его покупки на спотовом рынке. Портфель состоит из трех долей, сумма которых образует **Total Portfolio Value (TPV)**.

### Целевое распределение (Market Neutral):
1.  **BTC Long x5 (29%)**: Длинная позиция на фьючерсах с 5-м плечом.
2.  **BTC Short x5 (36%)**: Короткая позиция на фьючерсах с 5-м плечом.
3.  **BTC Margin Simulation (35%)**: Виртуальная позиция, где 35% маржи (USDT) на фьючерсном аккаунте математически ведут себя как BTC на споте.

**Математика нейтральности:**
Экспозиция (Notional) = `(0.29 * 5) + (-0.36 * 5) + (0.35 * 1) = 1.45 - 1.80 + 0.35 = 0`.
Любое изменение цены BTC компенсируется внутри портфеля, сохраняя TPV стабильным.

## 🏗 Архитектура и Логика работы

### 1. Расчёт TPV (Total Portfolio Value)
Поскольку маржа симулирует BTC, её стоимость меняется при каждом пересчёте:
`TPV = Real_Equity + (Virt_Current_Value - Virt_Allocated_USDT)`
Где `Real_Equity` — баланс биржи + нереализованный PnL фьючерсов.

### 2. Режим Hedge Mode
Бот управляет позициями `LONG` и `SHORT` одновременно по одному тикеру. Это позволяет независимо корректировать плечо для каждой стороны.

### 3. Ребалансировка "Трех долей"
При изменении цены доли "разъезжаются". Если отклонение любой из трех долей (Long, Short или Virtual) превышает порог (по умолчанию **0.5% - 4%**), бот:
1.  Рассчитывает целевой номинал (Notional) для Long и Short от **нового TPV**.
2.  Исполняет корректирующие рыночные ордера.
3.  Обновляет "базис" виртуального BTC (фиксирует прибыль/убыток маржи в математической модели).

### 4. Защитные механизмы
- **NaN Protection:** Защита от математических ошибок при резких скачках.
- **Max Change Limit:** Бот не может изменить позицию более чем на 50% от TPV за один цикл, что предотвращает "взрыв" портфеля на волатильности.
- **State Persistence:** Базисная цена и выделенная маржа сохраняются в `state.json`.

```text
futures_portfolio/
├── logs/                   # Лог-файлы работы бота
├── tests/                  # Модульные тесты
├── calculator.py           # Логика TPV и рыночно-нейтральных отклонений

├── connector.py            # Взаимодействие с API (Hedge Mode, Equity)

├── state.json              # Текущее состояние виртуальной доли BTC
└── Rebalancer.md           # Эта документация
```
