# Binance Futures Portfolio Rebalancer

Асинхронный инструмент на Python для автоматического поддержания рыночно-нейтрального портфеля на фьючерсном аккаунте Binance.

## 📌 Описание системы: Market Neutral 2.0
Система реализует стратегию динамического синтетического хеджирования. Портфель имитирует владение BTC без покупки актива на споте, используя свободную маржу аккаунта как третью активную ногу баланса.

### Целевое распределение (Market Neutral):
1.  **BTC Long x5 (29%)**: Длинная позиция на фьючерсах.
2.  **BTC Short x5 (36%)**: Короткая позиция на фьючерсах.
3.  **BTC Margin Simulation (35%)**: Виртуальная позиция BTC (x1), работающая на свободной марже.

**Математика нейтральности:**
Экспозиция (Notional) = `(0.29 * 5) + (-0.36 * 5) + (0.35 * 1) = 1.45 - 1.80 + 0.35 = 0`.
Система поддерживает нулевую дельту: прибыль одной части портфеля всегда компенсирует убыток другой.

## 🏗 Архитектура и Логика работы

### 1. Расчёт TPV (Total Portfolio Value)
Показатель TPV — это истинная стоимость вашего портфеля:
`TPV = Real_Equity + (Virt_Current_Value - Virt_Allocated_USDT)`
Где `Real_Equity` — баланс биржи + нереализованный PnL всех фьючерсных позиций.

### 2. Режим Hedge Mode
Бот работает в двустороннем режиме (Hedge Mode), независимо управляя `LONG` и `SHORT` позициями по BTCUSDT. Это критически важно для точной настройки плечей каждой стороны.

### 3. Ребалансировка "Трех долей"
При движении цены BTC доли отклоняются от целей. Если любое отклонение (Long, Short или Virtual) превышает порог (**0.5% - 4%**), бот:
1.  Вычисляет целевой номинал (Notional) для фьючерсов исходя из **нового TPV**.
2.  Выполняет сделки BUY/SELL для подгонки позиций.
3.  Обновляет базисную цену для виртуальной доли BTC в `state.json`.

## 🧪 Режимы тестирования

### 1. Бэктестинг (Backtesting)
Запуск на исторических данных FreqTrade. Позволяет мгновенно оценить эффективность за прошедшие месяцы.
```bash
python backtest_rebalance.py
```

### 2. Бумажная торговля (Paper Trading)
Работа в реальном времени на "живых" ценах Binance, но без риска реальными средствами. 
- Активируется флагом `"paper_mode": true` в `config.json`.
- Виртуальный баланс и позиции сохраняются в `paper_state.json`.
- Использует реальные API-запросы для получения цен и инфо о бирже.
```bash
python main.py
```
