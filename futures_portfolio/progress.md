## 🛠️ Настройка и Конфигурация

### 1. Переменные окружения (`.env`)
Для работы необходим файл `.env` в корне папки `futures_portfolio`:
- `BINANCE_API_KEY`: Ключ с правами на фьючерсную торговлю.
- `BINANCE_SECRET_KEY`: Секретный ключ.
- `TELEGRAM_BOT_TOKEN` & `TELEGRAM_CHAT_ID`: Для уведомлений.

### 2. Ключевые параметры `config.json`
- `max_bots`: Лимит одновременно запущенных пар (по умолчанию 5).
- `max_capital_usdt`: Ограничение капитала на один бот.
- `rebalance_threshold`: Порог отклонения доли для сделки (рекомендуется 0.004 - 0.005).
- `equity_trailing_stop_pct`: Защита от просадки от пика (10.0%).
- `limit_offset_pct`: Отступ лимитного ордера (0.1% для ZEC).

## 🏗️ Техническая Архитектура: Market Neutral 2.0

### Целевое распределение (Z-Logic):
1. **Long x5 (29%)**: Длинная позиция.
2. **Short x5 (36%)**: Короткая позиция (увеличенная доля хеджирует риск и стоимость маржи).
3. **Margin Simulation (35%)**: Виртуальная позиция (x1). 
   - *Как это работает:* Бот рассчитывает прибыль, которую принес бы актив, если бы мы купили его на споте на 35% капитала. Эта "бумажная" прибыль переливается в физические Long/Short позиции при каждой ребалансировке, имитируя владение активом без блокировки реальных средств.

### Механизмы защиты:
*   **Trailing Stop (10%):** Всегда активен. Защищает капитал от линейных трендов.
*   **Notional Guard (6 USDT):** Игнорирует микро-ордера, которые отклоняются биржей.
*   **Soft Hysteresis:** Удваивает порог ребаланса при нахождении в просадке, чтобы не "пилить" баланс на комиссиях.

## 🆘 Troubleshooting (Решение проблем)
- **Ошибка "Hedge Mode":** Зайдите в настройки Binance Futures -> Режим позиции -> выберите "Хеджирование".
- **Бот не совершает сделок:** Проверьте `rebalance_threshold`. Если цена изменилась менее чем на 1.5%, сделок не будет (это нормально).
- **Ошибка API "Order Value too small":** Сработал Notional Guard. Бот автоматически пропустит этот шаг, вмешательство не требуется.
