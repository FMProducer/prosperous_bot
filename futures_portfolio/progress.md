## 🗓 21 апреля 2026: Прорыв «Биржевой Логики»

### ✅ Ключевые достижения:
1.  **Value-Based Rebalancing (Gate.io Model):** Бот теперь считает доли на основе *реальной стоимости* (Allocated Capital + PnL). Это позволяет Short-ноге расти при падении цены, сигнализируя об избытке прибыли.
2.  **Global Cycle Trigger:** Внедрен принцип «Один за всех». Если любая из 3-х ног (L, S, V) пробивает порог 4%, бот пересчитывает и выравнивает весь портфель разом, исключая «рассинхрон».
3.  **Strict Priority (Phase 0):** Реализовано правило «Сначала деньги в карман». Бот всегда сначала продает излишки (высвобождая маржу и фиксируя профит), и только потом докупает дефицитные ноги.
4.  **Honest Math v5.3:** Бэктестер теперь учитывает средневзвешенную цену входа (Weighted Average Entry). Это устранило эффект «пинг-понга» и подтвердило доходность на дистанции 10 дней.

## 🗓 21 апреля 2026 (вечер): Исправление Логики Ребалансировки

### 🔧 Критическое исправление (`calculator.py`):
**Проблема:** При превышении порога `rebalance_threshold` (0.6%) любой ногой, бот ребалансировал **все три ноги** одновременно, даже если отклонение других ног было в пределах нормы.

**Решение:** Теперь каждая нога проверяется индивидуально:
```python
# Пропускаем, если отклонение не превышает порог
if abs(diff_share) <= threshold:
    continue
```

**Результат:**
- Ребалансируются только ноги, реально превысившие порог
- Уменьшено количество избыточных сделок
- Снижена нагрузка на комиссии
- Backtest и Paper Trading теперь полностью синхронизированы

## 🗓 21 апреля 2026 (поздний вечер): Архитектурные изменения

### 🔧 1. Сканер: 48ч → 24ч (rank_tickers.py)
**Проблема:** 48 часов слишком много для минутной торговли — рынок меняется быстрее.

**Решение:** Сканер теперь берет данные за **24 часа (1440 минут)** вместо 48ч (2880 минут).
- Более актуальная картина волатильности
- Быстрее реакция на изменение режима рынка
- Циклы считаются за актуальный период

### 💰 2. Сифонинг: Переписан на "Прибыль от каждой сделки"
**Старая логика:** Триггер по `siphoning_threshold_pct: 0.5%` — накапливал прибыль только при росте TPV выше порога.
**Проблема:** `initial_tpv` рос после каждого сифонинга → плывущий порог → мало резерва.

**Новая логика (`main.py`):**
```python
# При каждом reduce_only (продажа/закрытие):
if pos_side == "LONG":
    trade_pnl = (exec_price - avg_entry) * qty - commission
else:  # SHORT
    trade_pnl = (avg_entry - exec_price) * qty - commission

if trade_pnl > 0:
    siphoning_reserve += trade_pnl  # Сразу в сейф
```

**Преимущества:**
- ✅ Прибыль фиксируется мгновенно при каждой продаже
- ✅ Не зависит от общего роста TPV
- ✅ Больше резерва накапливается при волатильности
- ✅ Поддерживает market neutral стратегию

### 🔄 3. Реинвестирование: Изменена логика
**Старое:** Реинвестирование шло из прибыли портфеля (от `initial_tpv`).
**Новое:** Реинвестирование идет из **свободной маржи** (free margin):
```python
free_margin = real_equity - (total_tpv - virt_value)
to_reinvest = free_margin * reinvestment_ratio
```

**Изменение config.json:**
```json
"reinvestment_ratio": 0.0  // Пока отключено (было 0.05)
```

**Обоснование:** Реинвестирование включим только когда стратегия покажет устойчивую прибыльность. Сейчас приоритет — консервация капитала и накопление резерва.
