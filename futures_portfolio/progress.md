# 🛡 Логика ребалансировки «Гамма-Насос» (Версия 4.0.0)

## Выполненные задачи
- [x] **Aggregator Syntax Fix:** В `aggregator.py` исправлены критические синтаксические ошибки, вызванные некорректным экранированием кавычек (`\"` вместо `"`) и символов новой строки (`\\n` вместо `\n`). Файл полностью очищен и проверен на корректность компиляции.
- [x] **Notional Rebalancing (Safety First):** Система полностью переведена на расчет долей по номинальной стоимости (Exposure = Qty * Price). Это гарантирует рыночную нейтральность (Delta ≈ 0) и исключает рискованное усреднение против тренда.
- [x] **Leverage-Aware Price Fuse:** Предохранитель BLSH (Buy Low, Sell High) теперь учитывает плечо. Порог срабатывания по цене масштабируется как `threshold / leverage`, что позволяет боту совершать точные Notional-сделки, не блокируя их.
- [x] **Синхронизация Бэктестера:** `backtest_rebalance.py` теперь на 100% соответствует логике живого бота. Исправлены расчеты TPV (SSOT), добавлен Cold Start и поддержка динамического плеча из конфига.
- [x] **Оптимизация Логирования:** Троттлинг Price Fuse (1 сообщение на 20 циклов) устранил спам в логах, сохранив информативность Heartbeat.
- [x] **Гибридное отображение:** Калькулятор принимает решения по Номиналу (безопасность), но выводит доли в Heartbeat по Эквити (читаемость). Это решило проблему "отрицательного кэша" в логах.
- [x] **Синхронизация с Реальностью (SSOT):** Бот в REAL режиме теперь получает фактический `realizedPnl` и `commission` напрямую из API сделок Binance, исключая расчетные погрешности.

## 🗓 20 мая 2026: Протокол «Номинальный Хедж» (v4.0.0)

### 🛠 Переход на Notional-балансировку:
1.  **Calculator Refactoring:** В `calculator.py` внедрена формула `Exposure = (Qty * Price) / TPV`. Теперь при росте цены бот **сокращает** обе ноги (фиксируя прибыль и снижая риск), вместо того чтобы докупать убыточный шорт. Это фундаментальная защита от "палок" на альтах.
2.  **Price Fuse V2:** В `main.py` исправлен "затык" ребалансировок. Старый предохранитель ждал изменения цены на 1%, тогда как Notional-отклонение в 1% (при плече 5х) достигается уже при 0.2% движения цены. Теперь fuse понимает плечо и пропускает сделки вовремя.
3.  **Backtest High-Fidelity:** Бэктестер синхронизирован с `calculator.py`. Исправлена критическая ошибка "потери маржи" в TPV, результаты теперь реалистичны (например, JTO: +5.8% прибыли на +25% пампе с сохранением дельты).
4.  **Professional Limits:** Удалены все временные "костыли" для малых балансов. Установлен строгий лимит `min_notional_usdt: 7.0` для всех режимов. Капитал поднят до 260 USDT для обеспечения ликвидности Notional-сделок.
5.  **Log Cleanup:** Уменьшена частота сервисных сообщений `🛡️ FUSE (ORDER): blocked`. Лог сфокусирован на Heartbeat и реальных трейдах.
