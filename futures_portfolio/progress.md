## 🗓 27-28 апреля 2026: Синхронизация и Глобальная Оптимизация

### ✅ Ключевые достижения:
1.  **Unified Parameter Logic:** Все компоненты системы (`main.py`, `rank_tickers.py`, `backtest_rebalance.py`) теперь синхронно используют `initial_capital` и `rebalance_threshold` из `config.json`. Устранено расхождение между бэктестом и реальностью.
2.  **Strategy-Based Ranking:** Супервайзер переведен с отбора по "Alpha" на отбор по чистой **Strategy Profit (%)**. Это обеспечивает выбор тикеров, приносящих максимальный доход именно нашей стратегии.
3.  **Surgical Swarm Rotation (No-Restart Sync):** 
    - Исправлено "дергание" ботов. Теперь при обновлении роя (раз в 4 часа) Супервайзер не перезапускает весь список. 
    - Текущие прибыльные боты работают беспрерывно.
    - Только **новые** боты запускаются, а **вылетевшие** — останавливаются. Это экономит до 0.5% депо на лишних комиссиях при открытии/закрытии.
4.  **Emergency Stop Implementation:** В `main.py` добавлен флаг `--stop`. При исключении тикера из роя Супервайзер автоматически закрывает все его позиции (рыночными ордерами) и обнуляет файл состояния для чистого перезапуска в будущем.
5.  **Rank Tickers 5.0 (Clean Analytics):**
    - Полностью удален нерабочий функционал `SCORE`.
    - Ранжирование идет строго по количеству `CYCLES` (волатильность).
    - Добавлены метрики `MAX SPURT%`, `TREND EFF%` и `FUNDING%` в таблицу вывода.
    - Введен фильтр `CYCLES < 10` для отсева "мертвых" тикеров.
    - Сканер больше не трогает конфиг (теперь это делает только Супервайзер).
6.  **Telegram Proxy Fix:** Исправлена критическая ошибка `WinError 10060`. Отключение прокси для Binance теперь происходит локально в коде, не блокируя доступ `notifier.py` к серверам Telegram.

## 🛠 Команды управления (V3.0)

### 🚀 Глобальный запуск
- `pm2 start ecosystem.config.js` — **Единственная команда** для запуска всей системы (всех ботов + Супервайзера).
- `pm2 save` — Сохранение текущего состояния роя.

### 📊 Мониторинг
- `pm2 logs` — Логи всех активных ботов.
- `pm2 status` — Статус и потребление ресурсов каждого бота.
- `python rank_tickers.py` — Быстрый срез текущей активности рынка без изменения конфига.
